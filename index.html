1. Деление по типу лицензии и модели распространения

Open Source

Бесплатные (Коробочные)

Имеют открытый исходный код. Их можно скачать бесплатно, установить на свой хостинг и менять как угодно.

  • WordPress — лидер рынка для блогов и сайтов услуг.
  • Joomla! — для корпоративных порталов.
  • Drupal — для сложных и нагруженных проектов.
Commercial

Платные (Коробочные)

Требуют покупки лицензии. Обычно предлагают официальную техподдержку, высокий уровень защиты и готовые модули.

  • 1С-Битрикс — стандарт для e-commerce и бизнеса в СНГ.
  • DataLife Engine (DLE) — популярный движок для новостных порталов.
  • MODX (платные сборки) — гибкий инструмент для студий.
Облачные платформы

Конструкторы (SaaS)

Работают по подписке. Не нужно покупать хостинг и настраивать сервер — всё работает в браузере из коробки.

  • Tilda — идеален для лендингов и портфолио.
  • InSales — облачный движок для интернет-магазинов.
  • Shopify — мировой лидер облачной коммерции.
Custom

Самописные (Фреймворки)

Разрабатываются с нуля под конкретный уникальный проект. Не имеют готовой админки, всё пишется программистами.

  • Laravel / Symfony (PHP)
  • Django (Python)
  • Next.js / NestJS (JavaScript/TypeScript)

2. Деление по назначению

Универсальные CMS

Подходят для создания сайтов практически любого типа: от визитки до СМИ или небольшого магазина с помощью плагинов.

  • WordPress, MODX, Joomla!

E-commerce (Интернет-магазины)

Заточены под торговлю: есть корзина, фильтры товаров, интеграция с 1С, онлайн-кассами и службами доставки.

  • OpenCart, 1С-Битрикс, Magento, PrestaShop.

Блоги и медиа-порталы

Оптимизированы для работы с большим объёмом текстового и медиа-контента, комментариями и SEO.

  • Ghost, WordPress, DataLife Engine.

3. Деление по архитектуре

Традиционные (Монолитные)

Бэкенд (база данных, админка) и фронтенд (визуальная часть для пользователя) жёстко связаны в единую систему.

Headless CMS (Безголовые)

Система отвечает только за хранение контента и отдаёт его через API. Внешний вид можно написать на любом современном фреймворке (React, Vue) или вывести в мобильное приложение.

  • Strapi, Directus, Contentful.
